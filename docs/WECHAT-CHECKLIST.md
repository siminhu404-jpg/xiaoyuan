# 微信真机验证清单

每阶段发版前，把 dist 部署到任意 https 静态托管，在微信里打开走一遍：

- [ ] 标题页正常显示，字体不溢出
- [ ] 点「推门进院」后 3D 场景能渲染（WebGL 上下文创建成功）
- [ ] 小人行走流畅（体感 ≥ 30fps）
- [ ] 点击物件 → 走近 → 动效 → 记忆卡，全链路在触屏上无 300ms 延迟感
- [ ] 记忆卡文字大小在手机上可读（长辈视角）
- [ ] 「合上回忆」按钮在触屏上好按（≥ 44px 高）
- [ ] 手机旋转屏幕不崩、不变形
- [ ] 微信内打开无安全提示拦截
- [ ] 弱网（4G）下首屏加载 ≤ 10s
- [ ] iPhone（Safari 内核）与 Android（X5 内核）各过一遍
