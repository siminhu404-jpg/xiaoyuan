# 《姥姥家的小院》传播型 MVP：空间与体验设计说明

日期：2026-11-03
状态：待用户审阅

> 本文固定传播型 MVP 的体验和空间骨架。它只把用户已经确认的方向落成可执行设计，不进入正式建模和代码改造。2026-10-21 的总体设计文档仍保留为历史背景；本文对“传播型 MVP、两进院落、自由探索、小黑陪伴、文字+环境声”等决策进行更新。

## 1. 产品目标

### 一句话

用户从姥姥家最外面的门进入，在开放的两进院落中自由探索，带着小黑一路走到堂屋，在三分钟左右完成一次“回家”的体验。

### MVP 成功标准

- 用户无需阅读教程即可理解：打开门、走进院子、自由探索。
- 外门、外院、内院门、堂屋形成清晰的空间纵深。
- 用户可以按任意顺序探索菜地、葡萄架、枣树和压水井，不被任务或解锁阻断。
- 小黑始终是跟随人物的陪伴者，不承担导航、解锁或触发任务。
- 每个核心地点通过轻量动画、环境声和短文字产生反馈。
- 用户在堂屋获得一个明确但不强制的“回到家了”收束。
- 桌面端和手机端均可完成完整流程，首次加载和性能遵守现有预算。

## 2. 体验原则

1. **空间叙事优先于任务叙事**：用户通过走过院子理解关系，不显示任务列表。
2. **自由探索，不做区域锁定**：外门打开后，外院和内院均可到达；内院门只是空间节点，不是关卡。
3. **小黑只陪伴**：不主动带路、不指向热点、不负责解锁、不触发记忆内容。
4. **反馈短而轻**：靠近热点后产生局部变化，用户可以立即继续走，不被长弹窗打断。
5. **堂屋是情绪终点，不是游戏通关**：堂屋提供最完整的一段文字和氛围收束，但用户仍可自由返回院子。
6. **先验证空间，再制作资产**：灰盒验证通过前，不批量生成正式模型。

## 3. 空间布局

### 3.1 两进院落结构

```text
                         北 / 院子深处

┌──────────────────────────────────────┐
│  西房              堂屋             东房 │
│                                      │
│             内院 / 家庭记忆区          │
│                              压水井    │
│                                      │
│────────────── 内院门 ───────────────│
│                                      │
│  葡萄架 + 菜地       主通道      菜地 + 葡萄架 │
│                                      │
│        枣树       外院生活区         │
│                                      │
│                 外门                 │
└──────────────────────────────────────┘
                         南 / 进入方向
```

### 3.2 坐标约定

沿用项目已有坐标系：

- x 轴：东西方向，东为正
- z 轴：南北方向，北为负、南为正
- 现有场地范围：x ∈ [-12, 12]，z ∈ [-18, 20]
- 外门：南侧，约 `[0, 18]`
- 内院门：过渡区中部，约 `[0, -2]` 到 `[0, 0]` 的空间节点
- 堂屋：北侧，约 z = -15

这些是灰盒的初始锚点，不是最终美术模型坐标。正式调整时以可通行为优先。

### 3.3 区域定义

| 区域 | z 范围 | 主要内容 | 体验作用 |
|---|---:|---|---|
| 外门入口 | 16～20 | 外门、门墙、人物出生点 | 开始“回家” |
| 外院 | 6～16 | 枣树、东西侧房屋、生活杂物 | 建立院子第一印象 |
| 过渡区 | -2～6 | 内院门、菜地、葡萄架 | 自由探索和空间过渡 |
| 内院 | -12～-2 | 压水井、月季、西房、东房 | 更私密的家庭生活区域 |
| 堂屋终点 | -18～-12 | 堂屋门、门帘、暖光 | 情绪收束 |

### 3.4 通行要求

- 主通道保持约 2.2m 以上，允许人物和小黑并行。
- 热点前保留约 2.5～3m 的停留空间。
- 葡萄架柱、菜地边界、压水井不得侵入主通道。
- 房屋第一版作为边界和背景，不开放完整室内。
- 内院门两侧必须能绕行，不能形成不可逆的死路。
- 小黑跟随路径不应被窄门、墙角和装饰物频繁卡住。

## 4. 探索流程

```text
门外出生
  ↓
用户打开外门
  ↓
小黑从院内出现并跟随
  ↓
外院自由探索
  ├─ 枣树
  ├─ 西房 / 东房外部生活痕迹
  └─ 菜地、葡萄架
  ↓
用户自由进入内院
  ↓
压水井、月季、内院生活物件
  ↓
用户发现并进入堂屋门口
  ↓
堂屋展示最终记忆反馈
  ↓
用户可以继续自由返回院子
```

不设置：钥匙、任务清单、收集数量、强制路线、区域解锁、失败状态。

## 5. 核心互动点

MVP 先实现以下 6 个核心互动点；其余热点作为环境物件保留扩展位置。

| 顺序 | 热点 | 区域 | 反馈 | 内容形式 |
|---:|---|---|---|---|
| 1 | 外门 | 入口 | 双门打开、门轴声、院内环境声进入 | 一句“回家”文字 |
| 2 | 菜地 | 过渡区 | 叶片轻晃、蝴蝶或尘埃短暂出现 | 2～3 句短文字 + 风声 |
| 3 | 葡萄藤廊亭 | 过渡区 | 藤叶摆动、地面光斑移动 | 2～3 句短文字 + 虫鸣 |
| 4 | 枣树 | 外院 | 树冠轻晃、落下一两颗枣或叶片 | 2～3 句短文字 + 树叶声 |
| 5 | 压水井 | 内院 | 手柄下压、短暂水流和水盆回声 | 2～3 句短文字 + 压水声 |
| 6 | 堂屋 | 终点 | 门帘掀动、室内暖光、环境声变安静 | 最完整的一段短文字 |

交互规则沿用现有系统：用户点击热点后，人物走到 `standAt`，再触发动画和记忆反馈；点击普通地面只移动，不弹内容。

## 6. 小黑行为

小黑是跟随人物的陪伴角色：

- 人物移动时跟随，保持舒适距离。
- 人物停下时停下，可坐下、趴下或嗅闻。
- 人物与小黑距离过大时，小黑小跑追上。
- 人物靠近热点时，小黑只做自然待机，不触发热点。
- 人物进入堂屋附近时，小黑在人物身边或门口等待。
- 不用小黑作为方向指示器，不让它跑到下一个地点引导用户。

## 7. 记忆与声音

传播型 MVP 采用“短文字 + 环境声音”，暂不依赖老照片和家人语音。

### 文字

- 普通热点：2～3 句，控制在一次阅读可完成的长度。
- 堂屋：一段更完整但仍然简短的收束文字。
- 文字必须基于用户真实回忆，AI 只负责整理和润色，不虚构家庭细节。

### 声音

优先使用低成本环境声：

- 外门：门轴、门闩、远处风声
- 菜地：叶片、轻风、土壤中的细碎声
- 葡萄架：虫鸣、叶片、树影下的环境底噪
- 压水井：金属手柄、水流、铁盆回声
- 堂屋：环境声降低，保留门帘和室内微弱声音

声音应该是增强氛围，不是语音叙事；移动端无声时文字体验仍然完整。

## 8. 视觉方向

当前只固定到体验级别，不把用户提供的概念图直接当作最终美术风格。

暂定视觉基线：

- 暖色绘本低模
- 夏天傍晚或午后偏暖光
- 哑光材质、低反射、轻手绘纹理
- 建筑和物件保留北方农村生活比例
- 不做景区化、豪宅化、过度装饰化
- 场景物件应有板凳、水桶、晾衣绳、花盆、农具等生活痕迹
- 先通过灰盒确定构图和通行，再生成局部概念图

## 9. 第一批资产范围

### 必须制作

- 外门和门墙
- 外院地面与院墙
- 西房、东房外部体块
- 菜地和菜地边界
- 葡萄架与葡萄藤
- 内院门
- 堂屋门口和门帘
- 枣树
- 压水井
- 小人
- 小黑

### 第二批补充

- 月季
- 猫
- 墙头仙人掌
- 水桶、铁盆、板凳、花盆
- 晾衣绳、农具、杂物
- 房屋窗户和墙面细节

### MVP 暂不制作

- 完整屋内场景
- 可进入的所有房间
- 多人角色
- 复杂人物动作系统
- 四季切换
- 收集系统和成就
- 联机或账号

## 10. 灰盒验收标准

正式模型制作前，灰盒需要满足：

1. 从外门看得到内院门或堂屋方向的空间暗示。
2. 外门打开后，用户可以自由走到所有核心互动点。
3. 人物和小黑可以在主通道并行，不频繁碰撞或卡死。
4. 内院门是空间分层节点，但不是不可通过的关卡。
5. 堂屋在视觉和空间上像一个自然终点。
6. 跟随相机不会长期穿墙、遮挡人物或贴近建筑失控。
7. 手机触控下，用户可以完成进入、探索和到达堂屋。
8. 灰盒阶段不依赖正式模型、照片或复杂材质也能判断路线是否成立。
